**Your Stylist**

A web-based AI styling asistant that generates outfits for the user based on the uploaded clothes.
Uploaded pictures are described by AI and stored in a cloud database, allowing access from different devices.

**Features**

- Upload and store clothing images (Firebase Storage)
- AI-generated descriptions and metadata for each item
- Outfit recommendations from existing wardrobe
- User authentication and personal collections
- Clean UI with carousel-based outfit previews

**Tech Used**

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database & Auth: Firebase (Auth, Firestore, Storage)
- OpenAI API
